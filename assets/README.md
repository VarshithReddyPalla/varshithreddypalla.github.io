# CV / Lebenslauf

The German CV is stored as [`Varshith_Palla_Lebenslauf.pdf`](Varshith_Palla_Lebenslauf.pdf).

The navigation links "Lebenslauf" (German) and "CV" (English) both open this
same PDF in a new browser tab. Replace the file to update your CV; no code change
is needed. Publish the PDF together with the site.

To replace the CV:

1. Overwrite `assets/Varshith_Palla_Lebenslauf.pdf` with the updated PDF, keeping
   the exact filename and capitalization.
2. Preview the site and open the link in both German and English.
3. Commit the PDF and push it with the site updates.

If you rename the file, also update its `href` in `index.html` and the filename
in both README files. Both languages intentionally share one German document.
